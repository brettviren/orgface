Inspect configuration and cached state. Four subcommands; only =init=
and =clear-cache= change anything.

#+begin_src sh
org config show          # the resolved configuration
org config show --env    # also name each environment variable
org config init          # create the default config file if absent
org config paths         # the XDG locations and host file in use
org config clear-cache   # forget the cached org-roam locations
#+end_src

* show

Prints the config files actually loaded, in the order applied — the config
file then this host's file — or the XDG path it looked at and did not
find, then every setting as TOML, one table per section, in the
order they are declared. Unset settings appear as commented-out keys. With
=--env= each line also carries, as a trailing comment, the environment
variable that would set it. Secret settings, such as =embed.api_key=, are
shown commented out with their value withheld unless =--secrets= is given.

The output is a valid config file, so a variant is easy to start:

#+begin_src sh
org config show > other.toml   # then edit other.toml
org -c other.toml store ...
#+end_src

This is the fastest answer to "why is it using *that* store": the value
printed is the one the command would use, after all
[[file:configuration.org][layers]] have been applied.

* init

Creates the configuration directory and writes a =config.toml= holding
every setting at its built-in default, each preceded by a comment saying
what it does. If the file already exists it is left untouched.

* paths

Prints the configuration file, state directory and cache directory in use.
See [[file:xdg-locations.org][XDG locations]] for what belongs in each.

* clear-cache

Removes the cached org-roam locations, so the next command that needs them
asks the [[file:emacs-daemon.org][daemon]] again. Use it after moving your org-roam directory. It
says whether there was anything to remove.

Only locations are cached, and a warm cache is an optimisation rather than
a requirement: if the cache cannot be written, nothing fails.
