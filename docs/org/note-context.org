[[file:command-note.org][org note]] records not only what was written but where and when. Four facts
are gathered and turned into an ordinary capture template body, so a note
is selected, filled and escaped by the same route as a commit.

- An *inactive* org timestamp, to the second.
- =DIRECTORY=, =HOST= and =USER= as properties on the headline.
- Headline tags saying where that was.

The timestamp is inactive on purpose: a record of when something was
written is not something to be done, and has no business in your agenda.

* The tags

- =home= :: when the working directory is your =$HOME=.
- The repository :: the name of the enclosing git working tree, if the
  directory or any above it holds a =.git=.

A =.git= *file* counts as well as a directory, so worktrees and submodules
are tagged too.

Org accepts only alphanumerics and =_@#= in a tag, so a repository named
=orgface= is tagged =orgface=: runs of anything else collapse
to a single underscore, and a name with nothing usable left in it is not
tagged at all.

* Reproducible by construction

Nothing in the context module reads a clock or an environment on its own
behalf. =gather()= takes every fact as an argument and falls back to the
running process only for the ones it was not given, which is what lets a
test pin the time, the host and the directory and assert on the exact text.
