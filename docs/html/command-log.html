org log

command user capture

Show recent daily note entries, newest first, through your pager. Each top level heading in a daily note is one entry, which makes this the analogue of git log.

Daily notes are read straight from disk, so this works whether or not Emacs is running. 

org log --today
org log --since "2 weeks ago" --oneline
org log -n 5 --reverse

Options

OptionMeaning
--todayOnly entries written today
--since, --afterAt or after a date
--until, --beforeAt or before a date
-n, --max-countLimit to the N most recent entries
--onelineOne compact line per entry
--reverseOldest first
--colorauto (default), always, never
--no-pagerWrite straight to stdout
--refreshRe-read org-roam locations from Emacs

--today cannot be combined with --since or --until; saying both is a question about which was meant, so it is reported rather than resolved.

An upper bound named as a bare day covers that whole day, so --until 2026-07-30 includes everything written on the 30th. Date spellings are their own subject: see Date spellings.

What it does not show

Notes written by org note live in a topic rather than the dailies, so they are not reported here. A log is a chronology; read a topic with org visit -T.

Finding nothing is reported on standard error and exits non-zero, so a shell loop can tell "no entries" from "entries printed".
