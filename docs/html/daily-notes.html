Daily notes

concept user capture

A daily note is the org-roam file for one date, named YYYY-MM-DD.org by the stock dailies target and living under org-roam-dailies-directory.

Each top level heading in that file is one entry — the unit org commit writes and org log reports. That is what makes an entry the natural analogue of a commit: a titled, timestamped thing you added, in a file that accumulates them.

Content ahead of the first heading becomes a preamble entry rather than being dropped, so a hand-edited file still reports everything it holds.

Read from disk, not from Emacs

Daily notes are plain files, so org log reads them directly and works whether or not the daemon is running. Only the locations of the notes come from Emacs, and those are cached — see XDG locations.

Set roam.directory and roam.dailies_directory explicitly and org log never consults Emacs at all.

What an entry looks like

* Fixed the thing
[2026-08-04 Tue 13:45]

Took all day.

A line holding nothing but a timestamp — what the stock template's %T produces — is the entry's date rather than part of what was written, so it is reported as the date instead of twice.
