User guide

guide user

For someone using orgface rather than changing it. Two orderings of the same pages: read across the first to get the shape of the tool, then down the second for whichever part you need.

Quick start

alias org=orgface

org commit -m "Fixed the thing" -m "Took all day."
org note -m "Fixed the thing" -m "Took all day."
org log --today
org visit yesterday
org daemon status

org store add notes.org
org store list
org search deadline --scope heading

If something surprises you

A command used a store you did not expect
=org config show=, and see Configuration on which layer wins.
A search found nothing
check the backend can index at all — org search explains which can.
A file came back reformatted
The org file backend says what writing normalises, and Roadmap what is known broken.
Emacs was not touched
only some commands need it; The Emacs daemon lists which.
