Installation

reference user developer

orgface uses uv for development. 

uv sync                # set up the development area
uv run pytest          # run the tests
uv run orgface  # run the CLI

Extras

The base install is deliberately small: click, jinja2 and pydantic. Anything that only some users need is an optional extra.

orgfs
adds org-parser, the standalone tree-sitter parser. Needed by the org file backend and by org store add on an .org file.
semantic
adds sqlite-vec, the vector index behind semantic search.
service
adds fastapi and fastmcp, behind org serve and org mcp. 
uv sync --extra orgfs            # one extra
pip install 'orgface[orgfs,semantic,service]'

A command needing an extra that is not installed says which one supplies it, rather than failing with an import error.

The development area

The dev dependency group pulls in every extra, because the test suite covers every backend and both service front ends. A plain uv sync is therefore enough to run the whole suite; see Testing.

Emacs

Only the capture half needs Emacs, and it needs org-roam in it. The store half runs with no Emacs installed at all — except the Emacs backend, which also wants ox-json.
