org serve

command user service

Serve the store over HTTP: the same operations org store and org search offer, as a typed JSON API. 

uv sync --extra service      # or: pip install 'orgface[service]'

org serve                    # http://127.0.0.1:8765
org serve --host 0.0.0.0 --port 9000
org serve --schema           # print the OpenAPI document, serve nothing

No authentication

It binds to localhost and has no authentication. It is for local tools; it is not something to expose to a network. Anyone who can reach the port can read and delete your notes.

The store is opened per request

Rather than holding one connection for the server's lifetime, which would serialise every request behind it and go on holding a file you may want to move. See The HTTP API for the operation list and the status codes.

--schema

Prints the OpenAPI document and exits. That document is not a by-product: org mcp derives its tools from it, so it is the shared description both front ends are generated from.
