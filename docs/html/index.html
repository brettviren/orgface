orgface documentation

guide user developer

orgface does some Emacs org things quickly from the command line: it captures notes into org-roam through a private Emacs daemon, and it keeps org content in a store you can list, search, edit a piece at a time, and serve to other programs.

These pages are a wiki. One concept per page, linked wherever concepts meet. Two guides give a reading order through them.
