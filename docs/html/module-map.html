Module map

reference developer

Two packages under src/. The dependency runs one way: org_store never imports orgface.

orgface — the CLI

cli.py
the click group, the shared context, command registration.
commands/
one module per command group, doing parsing and presentation only.
ui.py
all rendering for people, including colour resolution and paging.
config.py
the layered settings, declared once in SETTINGS.
xdgpaths.py, cache.py
XDG locations and the location cache.
storage.py
turning configuration into an open store; rendering.py where a rendering is written.
emacs.py, elisp.py, bootstrap.el
the daemon and the JSON bridge.
templates.py
capture template selection, filling and escaping.
context.py
the context a note records.
dailies.py, dates.py, locations.py
reading daily notes, date spellings, and where org-roam keeps things.

org_store — the library

model.py
the canonical document; schema.py renders it to JSON Schema.
refs.py
ref computation; tree.py walks and locates nodes.
text.py
what the text of a node is; extract.py the index rows and the content hash.
service.py
CRUDS; store.py the backend protocol and the error types.
backends/
sqlite, orgfs, emacsfs, and the table that names them.
adapters/orgparser.py
org text to canonical model, no Emacs.
render/
canonical model back to org text, one template per node type.
search.py, embed.py
query shapes and the embedder protocol.
export/
rendering a document as HTML or another format.
sync.py
copying between stores.
api.py, mcp.py
the HTTP API and the MCP tools derived from it.
